=============================================
8. IF SOMETHING FAILS
=============================================

Check server-side:
  1. SSH to server
  2. cd ~/coderhero.duncowebsolutions.co.ke
  3. Check logs: tail -50 storage/logs/laravel.log
  4. Verify storage link: ls -la public/storage
  5. If storage link missing: php artisan storage:link

Check APK-side:
  1. Force close and reopen the app
  2. Clear app data if needed (Settings > Apps > Coder's Hero > Clear Data)
  3. Reinstall the APK

Report issues with:
  - Which role (student/parent/teacher/admin)
  - Which screen/menu
  - Exact error message
  - Screenshot if possible
